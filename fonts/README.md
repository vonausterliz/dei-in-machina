# I caratteri

**Cardo** — David J. Perry, Scholars Fonts.
Un carattere pensato per i classicisti: ha il greco politonico, le legature e i segni
diacritici che servono a scrivere Ὀδυσσεύς senza scorciatoie. È la ragione per cui i
distintivi degli dèi nella Vista Olimpo sono lettere greche e non emoji — quelle il font
non le ha, e uscirebbero come quadratini vuoti.
